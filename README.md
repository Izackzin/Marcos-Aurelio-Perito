# Site Institucional — Marcos Aurélio Ramos

Site institucional de página única para o **Marcos Aurélio Ramos**, perito judicial e avaliador de imóveis no Distrito Federal. Desenvolvido em HTML, CSS e JavaScript puro, sem dependências externas.

## 📋 Descrição

Página institucional profissional voltada a escritórios de advocacia e demandas judiciais, com visual sóbrio em azul-marinho, branco e dourado. O site apresenta os serviços, a metodologia de trabalho, as áreas de atuação e os canais de contato do perito.

## ✨ Seções do site

- **Hero** — nome, título, credenciais (CRECI-DF, CNAI, TJDFT | TRF | TRT) e foto do profissional
- **Sobre** — formação e especializações
- **Serviços** — 4 cards: laudo de avaliação, assistência técnica, consultoria para litígios e perícia extrajudicial
- **Metodologia** — fluxo de trabalho em etapas
- **Áreas de atendimento** — execuções, inventário, possessórias, desapropriação etc.
- **Base normativa** — Lei 6.530/1978, ABNT NBR 14.653 e Resolução COFECI 1.066/2007
- **Contato** — botão de WhatsApp e e-mail

## 🚀 Como usar

1. Baixe o arquivo `index.html`.
2. Coloque a **foto** do profissional na mesma pasta, com o nome `foto-marcos.jpg`.
3. Coloque a **logo** na mesma pasta, com o nome `logo-marcos.png`.
4. Abra o `index.html` no navegador.

> A foto e a logo são carregadas automaticamente quando os arquivos estão na mesma pasta do HTML.
